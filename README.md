## 📖 Tentang Proyek

**Skilora Academy** adalah platform kursus online terdepan yang dirancang untuk membantu mahasiswa, fresh graduate, dan profesional menguasai keahlian digital masa depan melalui kurikulum berbasis proyek nyata (*project-based learning*).

Bidang studi utama meliputi:
- **Web Development**: HTML, CSS, JavaScript, Bootstrap 5, React.
- **UI/UX Design**: Figma, Adobe XD, Design Systems, Auto-layout, User Testing.
- **Mobile Development**: Flutter & Dart, REST API, BLoC State Management.
- **3D Modelling & Art**: 3D Blender, Adobe Illustrator, Karakter Vektor & Logo.

---

## ✨ Fitur Unggulan

- 🔍 **Live Search & Filter Kategori**: Pencarian kursus secara *real-time* dan filter kategori dinamis di halaman Katalog Kelas.
- 🛒 **Modal Detail & Simulasi Transaksi**: Pratinjau silabus lengkap, daftar fasilitas (*lifetime access*, sertifikat, Discord), dan simulasi pendaftaran instan.
- 💬 **Kisah Sukses Nyata Alumni**: Ulasan asli dari 9 alumni yang telah berkarier di industri teknologi.
- ❓ **Pusat Bantuan & FAQ Interaktif**: Accordion tanya-jawab transparan dan tombol konsultasi WhatsApp terintegrasi.
- 📜 **Syarat & Ketentuan Terstruktur**: Panduan lisensi akun, hak cipta materi, serta kebijakan garansi kepuasan 7 hari.
- 📱 **Desain Responsif & Modern**: Dilengkapi animasi AOS, typography *Plus Jakarta Sans*, dan efek *glassmorphism* pada navbar.

## 🛠️ Panduan Instalasi & Menjalankan Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/Pekesxyz/skilora-academy.git
   cd skilora-academy
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173`.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```
